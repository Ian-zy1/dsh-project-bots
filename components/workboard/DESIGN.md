# Workboard 界面

Workboard 用来定位当前进展，再打开相关快照或交付证据。桌面保留项目栏、需求列表和阅读区，手机按同一顺序排布。进展在需求详情居首，背景、任务快照、长 Markdown 与候选证据按需展开。

界面采用浅蓝项目导航、冷白阅读面和深蓝正文。蓝色标识当前选择与行动，绿色和琥珀色仅表明成功与阻塞。需求标题后显示版本和编号，步骤使用已有 Phosphor 图标配合明确的文字。标识和 SHA 使用等宽字体，正文用系统中文字体与 Inter 回退，上限约 72 字符宽。

保留空态、加载、异常、键盘焦点与窄屏换行。结构化正文在浏览器内排版，读取和写入 API 沿用现有契约。验收覆盖 1440 和 390 像素、页内快照、派活超时及 Owner 评审通过。

执行轮次用纵向时间轴与间距分组。当前节点用浅蓝底，退回节点用琥珀底，普通记录用轻边界。点击节点在原位展开证据，返工原因入口定位并聚焦对应评审。轻量淡入和选中反馈参考 React Bits，系统开启减少动态效果时使用即时切换。
